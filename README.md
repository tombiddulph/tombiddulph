# Tom Biddulph

I'm a .NET and cloud engineer based in Leeds, building developer tools, distributed systems, and occasionally entire interfaces disguised as terminals.

Explore my work through [an interactive terminal portfolio](https://terminal.tommyb.dev), built with Blazor, .NET 10, and C# 14.

## Selected work

- **[Service Bus Emulator Explorer](https://github.com/tombiddulph/Service-Bus-Emulator-Explorer)** - A web UI for exploring queues, topics, subscriptions, messages, and dead-letter queues in the Azure Service Bus Emulator.
- **[BlazorTerm](https://github.com/tombiddulph/BlazorTerm)** - An iTerm-inspired portfolio with a real shell, composable pipelines, OpenTelemetry traces, and a virtual filesystem.
- **[Azure Functions Isolated Worker Test Host](https://github.com/tombiddulph/azure-functions-dotnet-worker-test-host)** - A test harness for running integration tests against .NET isolated Functions without Azure infrastructure.
